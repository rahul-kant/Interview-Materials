# Preparation Roadmap - 4 Month Plan

## Overview
This is a **4-month intensive preparation plan** designed for a senior Java engineer with 14 years of experience targeting FAANG companies. Adjust the timeline based on your availability.

**Weekly Time Commitment**: 15-20 hours
- **Weekdays**: 2-3 hours/day
- **Weekends**: 4-5 hours/day

## Problem-Solving Strategy

### For Coding Problems:
1. **Understand** (5 mins): Read carefully, clarify ambiguities
2. **Examples** (3 mins): Walk through examples
3. **Approach** (5 mins): Think of brute force → optimize
4. **Code** (20 mins): Write clean, bug-free code
5. **Test** (5 mins): Test with edge cases
6. **Optimize** (7 mins): Discuss time/space complexity

**Total**: 45 minutes per problem (interview pace)

### For System Design:
1. **Requirements** (5 mins): Functional & non-functional
2. **Estimations** (5 mins): Scale, storage, bandwidth
3. **API Design** (5 mins): Core APIs
4. **High-level Design** (10 mins): Components diagram
5. **Deep Dive** (15 mins): Core component details
6. **Trade-offs** (5 mins): Discuss alternatives

**Total**: 45 minutes (then discuss remaining time)

## Adjustment Guidelines

### If You Have More Time (6 months):
- Spend 2 months on Month 1-2 content

- Solve 600+ problems
- More system design practice

### If You Have Less Time (2-3 months):
- Focus on patterns over quantity
- Skip Easy problems, start with Medium
- Intensive system design (1 design/day)
- More mock interviews

### If You're Already Strong in DSA:
- Spend Week 1-4 on quick review
- Jump to Hard problems faster

## Important Tips

1. **Consistency > Intensity**: Daily practice is better than weekend binge
2. **Understand > Memorize**: Focus on patterns, not solutions
3. **Write Code**: Don't just read solutions
4. **Time Yourself**: Practice with timer (45 mins)
5. **Mock Interviews**: Essential for senior roles
6. **Take Breaks**: Rest days prevent burnout
7. **Track Progress**: Use spreadsheet or notion
8. **Join Communities**: LeetCode discuss, Blind, Reddit
