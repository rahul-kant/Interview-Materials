# Object-Oriented Programming Basics

## 📖 Introduction

Object-Oriented Programming (OOP) is a programming paradigm that organizes code around objects rather than functions and logic. Understanding OOP is fundamental to mastering Low-Level Design.

## 🎯 Four Pillars of OOP

1. **Encapsulation** - Bundling data and methods that work on that data
2. **Abstraction** - Hiding complex implementation details
3. **Inheritance** - Creating new classes from existing ones
4. **Polymorphism** - Objects taking multiple forms
