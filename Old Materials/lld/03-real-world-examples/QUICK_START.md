## 🎤 Interview Day Strategy

### First 5 Minutes:
✅ **Clarify Requirements**
- Ask: Functional requirements?
- Ask: Scale (users, requests)?
- Ask: Focus areas (performance, scalability)?
- Ask: Any constraints?

### Next 10 Minutes:
✅ **High-Level Design**
- List: Core entities
- Sketch: Basic workflow
- Mention: Design patterns you'll use
- Discuss: Initial tradeoffs

### Next 20 Minutes:
✅ **Detailed Design**
- Draw: Class diagram
- Define: Key interfaces
- Explain: Relationships
- Think aloud: Design decisions

### Next 15 Minutes:
✅ **Implementation**
- Write: Clean code
- Add: Comments for "why"
- Handle: Edge cases
- Make it: Extensible

### Last 10 Minutes:
✅ **Discussion**
- Discuss: Scalability
- Mention: Alternative approaches
- Talk about: Tradeoffs
- Be ready: For follow-up questions

## 🎯 Common Mistakes to Avoid

### Don't:
❌ Jump to code without design
❌ Ignore requirements gathering
❌ Overengineer simple problems
❌ Use poor variable names
❌ Forget error handling
❌ Ignore edge cases
❌ Make it too tightly coupled
❌ Stay silent during design

### Do:
✅ Ask clarifying questions
✅ Start with simple design
✅ Think out loud
✅ Use design patterns appropriately
✅ Write clean, readable code
✅ Consider scalability
✅ Discuss tradeoffs
✅ Handle edge cases
